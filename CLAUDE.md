# GTMQoL

Start of a session:
1. Read `context.md` (branches, known unfixed bugs, to-dos, open questions). Update it when a piece of work is done.
2. Everything else (the user's and this project's rules, build setup, design) is in agent-toolkit's doc index: read
   the instructions tree its server lists at start (`instructions.project`). Saved as text in `.agent-toolkit/index/`
   (`index_save`, then commit); `.agent-toolkit/cache/` is local. With both worktrees open, pass `repo`.
